# Chess Vision — Complete Android Project

تطبيق أندرويد متكامل لتحليل رقع الشطرنج مباشرة من الشاشة ورسم سهم أفضل نقلة فوق الرقعة.

## الميزات المُنفّذة
- **التقاط الشاشة الآمن (`MediaProjection`)**: دعم كامل لأندرويد 8 إلى أندرويد 15+ (بما في ذلك `MediaProjection.Callback` وإذن الإشعارات `POST_NOTIFICATIONS`).
- **كشف رقعة الشطرنج تلقائياً (`BoardDetector.kt`)**: تحديد موقع الرقعة 8×8 وتباين المربعات تلقائياً.
- **التعرف على القطع وألوانها (`PieceClassifier.kt`)**: فصل القطع البيضاء والسوداء وتصنيف أشكالها.
- **تتبع النقلات وتوليد FEN (`ChessGameTracker.kt` + `ChessLogic.kt`)**: إعادة بناء النقلات القانونية تلقائياً مع الحفاظ على حقوق التبييت والأخذ بالمرور.
- **محرك Stockfish + محرك احتياطي (`StockfishEngine.kt`)**: تشغيل Stockfish عبر بروتوكول UCI مع 5 مستويات قوة (من مبتدئ ~1320 إلى أقصى قوة)، بالإضافة إلى محرك Alpha-Beta مدمج كاحتياط.
- **رسم سهم أفضل نقلة + لوحة تحكم عائمة (`OverlayArrowView.kt` + `OverlayController.kt`)**: سهم واضح مع التقييم (`+1.45` أو `M3`) ولوحة عائمة قابلة للسحب للتحليل الفوري أو تبديل الدور أو الإيقاف.

## طريقة استخراج ملف APK جاهز للتثبيت
1. فك ضغط هذا الملف وارفع محتوياته إلى مستودع (Repository) على **GitHub**.
2. افتح تبويب **Actions** في المستودع واختر **Build Android APK** ثم اضغط **Run workflow** (أو يبدأ تلقائياً عند الرفع لفرع `main`).
3. يقوم السيرفر تلقائياً بتحميل محرك **Stockfish** الرسمي للأندرويد وتجميع المشروع.
4. بعد انتهاء البناء، نزّل ملف **ChessVision-debug-apk** من قسم **Artifacts** وثبّته على موبايلك.
